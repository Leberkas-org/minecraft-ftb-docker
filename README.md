# Minecraft FTB Docker image

This is an easy to use docker image for any [FTB Modpack](https://feed-the-beast.com/modpacks?sort=featured) you want to play. Build the image by the provided script and run the finished container. 

Some of the modpacks i play myself you can dowload from the [Docker Hub](https://hub.docker.com/repositories/dirnei)
