Configure

    
Environment variables

    
Only EULA is required. Everything else is optional, and a value is written to server.properties only when you set it — after the first start that file is yours to edit.

    

      

        
VariableDefaultWhat it does

        
          
EULArequiredSet to true to accept the Minecraft EULA. The server will not start otherwise.

          
MEMORYpack defaultHeap size, e.g. 10G. Change it any time — no rebuild.

          
MOTD—Message shown in the server list.

          
DIFFICULTY—peaceful, easy, normal or hard.

          
MAX_PLAYERS—Player cap.

          
LEVEL_SEED—World seed. Applies on the first start only.

          
ENABLE_RCONfalseTurns on remote console. Needs RCON_PASSWORD.

          
SERVER_PORT25565Listen port. Leave unset to keep whatever is in server.properties.

          
EXTRA_JVM_ARGS—Extra JVM flags, space separated.

          
PUID / PGID1000Owner of /data, to match your host user.

        
      

    

  






  

    
Keep your world

    
Everything lives in one volume

    
Back up ./data and you have backed up the server. The modpack lives in the image and your data does not, so pulling a newer image keeps your world.

    
    
      
  • data/worldThe world itself — chunks, player inventories, mod data.
    • 
      
  • data/server.propertiesServer settings. Yours to edit; nothing overwrites it.
    • 
      
  • data/ops.jsonOperators.
    • 
      
  • data/whitelist.jsonWhitelisted players.
    • 
      
  • data/banned-players.jsonBans, alongside banned-ips.json.
    • 
      
  • data/usercache.jsonName to UUID cache.
    • 
      
  • data/logsServer logs, rotated per start.
    • 
      
  • data/crash-reportsKept here on purpose, so a crash report outlives the container it killed.
    • 
      
  • data/backupsWhatever your backup mod writes.
    • 
    

    
Drop any other file in data/ and it is copied into the server at the same path on start — data/server-icon.png, or a single config out of the pack's hundreds at data/config/<mod>.toml. Your copy is re-applied every start, so it stays the source of truth.

    
Stop with docker compose stop, never by killing the container. The server is asked to save and shut down cleanly, which is why stop_grace_period is 120s — a modded server killed mid-save corrupts its region files.

  






  

    
Contribute

    
Add a modpack

    
Any pack on the modpacks.ch index can be built — CurseForge packs and FTB's own. Adding one means adding a single file to packs/.

    

      
Find the id
Project ID in the CurseForge sidebar, or the number in an FTB pack URL.

      
Generate
.\tools\propose-pack.ps1 -Id 1298402 writes the pack file: newest release, tag, versions, heap.

      
Open a PR
Add the build label and CI builds the image and boots the server to prove the pack starts.

      
Merge
Publishes the image. A daily job then opens a PR whenever the pack has a newer release.

    

    
Booting the server is the check that matters. One pack built perfectly and still refused to start, because a mod the manifest listed as server-side needed a client-only dependency — only a real boot catches that.
